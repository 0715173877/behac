Admin / Owner Guide

As an Admin or Owner, you have full access to manage the school system. This guide walks you through all the key features.

1. Getting Started

1
Log In

Go to the login page and enter your username and password provided by the system administrator.

2
Dashboard Overview

After logging in, you'll see the Admin Dashboard showing key stats: total pupils, teachers, classes, parents, and revenue summaries.

3
Navigate the Sidebar

Use the sidebar menu on the left to access different sections. Click the hamburger icon () on mobile to show/hide it.

2. Managing Pupils

1
View All Pupils

Click Pupils in the sidebar under "Records" to see a list of all enrolled pupils.

2
Add a New Pupil

Click the Add Pupil button and fill in the required details (name, date of birth, class, parent info, etc.).

3
Edit or Delete a Pupil

Click the edit () or delete () icons next to any pupil record.

4
Approve Applications

When parents apply online via the website, their applications appear under Applications in the sidebar. Click to review, approve, or reject them. Approved pupils are automatically enrolled.

3. Managing Teachers & Users

1
Teachers

Click Teachers to view, add, or manage teacher profiles. Each teacher can be assigned to specific classes.

2
Users

Click Users to manage system login accounts. You can create accounts for teachers, accountants, and parents, and assign their roles (groups).

Tip: When creating a parent user, use the parent's email as the username. The default password is parent123 — remind parents to change it.

4. Academics Management

1
Classes

Set up class levels (e.g., Standard 1, Standard 2, Form 1, etc.) under Classes in the Academics section.

2
Subjects

Add subjects (Mathematics, English, Science, etc.) and assign them to class levels.

3
Academic Years & Terms

Set up academic years and terms under Administration → Academic Years / Terms. Mark the current year as active.

4
Timetables

Create class timetables by assigning subjects, teachers, time periods, and days of the week.

5. Finance Management

1
Fee Categories

Create fee categories (e.g., Tuition, Transport, Lunch) under Finance → Fee Categories.

2
Fee Structures

Set the amount for each fee category per class level under Fee Structures.

3
View Reports

Access financial reports, outstanding balances, and payment summaries from the Finance section.

6. Behavior & Achievements

1
Behavior Records

Record positive or negative behavior incidents for pupils. These are visible to parents in their dashboard.

2
Achievements

Award achievements or certificates to pupils for academic excellence, sports, or good conduct.

7. Django Admin Panel

1
Access Admin Panel

Click Admin Panel in the sidebar to access the Django admin interface for advanced management.

Caution: The Django Admin Panel gives you direct access to the database. Be careful when editing or deleting records here.

8. Managing the Public Website

1
View Website

Click Website in the sidebar to open the public-facing school website in a new tab.

2
Update School Info

Go to the Django Admin Panel to update school name, logo, colors, and other settings under the Core app.
